## LifeOS v0.1.1

Windows desktop fixes with English-first bilingual UI.

### Fixed

- SQLite `database is locked` errors during plan imports: added WAL, busy timeout, lock retries, and a single-connection import transaction.
- Overlapping or excessively tall timeline cards: redesigned the agenda with a time rail, readable task cards, wrapping text, and dedicated actions.
- Desktop quick-panel scrolling: long task lists scroll within the window while the header and settings remain fixed.
- Notifications and refreshes jumping to the top: floating, dismissible messages and background refreshes keep the page mounted and input focus intact.

### Download and update

Download `LifeOS-v0.1.1-windows-x64-en.zip` or `LifeOS-v0.1.1-windows-x64.zip`. Both contain the same bilingual app, defaulting to English on a fresh install. Switch to Chinese using the top-bar language button.

Close the old app and its quick panel, extract the archive, and run `LifeOS.exe`. Windows x64 with WebView2 Runtime is required. Your existing local app data is retained; the archive contains no personal database or logs.

SHA-256 checksums are attached as `SHA256SUMS.txt`.

### Validation

8 tests passed, including the background-refresh focus regression test. TypeScript/Vite production build and the Windows Tauri release build passed.

## 中文说明

本次为 Windows 桌面修正版，默认英文，可切换中文。

### 修正

- SQLite 导入时的 `database is locked` 错误：增加 WAL、锁等待超时、重试，并通过同一连接执行导入事务。
- 时间轴任务堆叠、卡片过度拉长：改为左侧时间连线与右侧任务卡片，支持文字换行，操作区独立显示。
- 桌面便栏无法上下滚动：长任务列表可在窗口内滚动，顶部拖动栏与设置保持固定。
- 提示消息及刷新导致跳回顶部：使用可关闭的浮动提示，后台刷新保留当前页面和输入焦点。

### 下载与更新

下载 `LifeOS-v0.1.1-windows-x64-en.zip` 或 `LifeOS-v0.1.1-windows-x64.zip`，两个包包含相同的双语应用。

关闭旧程序和便栏，解压新版后双击 `LifeOS.exe`。需要 Windows x64 和 WebView2 Runtime。原有本地应用数据保留；发布包不包含个人数据库和日志。

SHA-256 校验值见附件 `SHA256SUMS.txt`。

### 验证

8 项测试通过，包括后台刷新保留输入焦点的回归测试；TypeScript/Vite 生产构建与 Windows Tauri 构建通过。
