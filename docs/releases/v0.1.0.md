## LifeOS v0.1.0

首个可运行的 Windows 桌面 MVP。

### 包含

- 今日计划、13:00–17:00 时间轴和任务打卡
- LifeOS JSON v1 导入、预览和严格验证
- SQLite 本地持久化、历史记录和每日复盘
- `daily_review` JSON 与全部数据备份导出
- 可拖动、置顶、可调透明度和大小的桌面便栏
- 可调整大小的便栏字体，英文使用 Consolas
- 深色模式、测试和完整开发文档
- 中文 README 和英文 README

### Windows 运行

下载并解压 `LifeOS-v0.1.0-windows-x64.zip`，双击其中的 `LifeOS.exe`。这是便携版，不需要安装器。需要 WebView2 Runtime。

### 校验

源码和协议见仓库 `main` 分支，版本标签为 `v0.1.0`。
